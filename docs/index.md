
# PDFMathTranslate Next

Translate scientific PDFs while preserving formulas, figures and page layout.
The application provides a local WebUI, a command line interface and a Python API,
with monolingual and bilingual PDF output powered by BabelDOC.

The WebUI listens on `127.0.0.1` by default. Network access requires an explicit
`--server-name` setting; use authentication and a trusted network when enabling it.
Public sharing requires `--share` and is never enabled as a fallback.
