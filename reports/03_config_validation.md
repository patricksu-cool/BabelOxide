# 第三階段：Config 路徑修改與驗證（2026-10-22）

## 實作

- 所有內建設定檔仍沿用原本名稱與 TOML 格式，但預設目錄改為程式旁的 `config/`。原始碼執行時為專案根目錄；一般凍結 EXE 使用可執行檔目錄；PyStand 啟動腳本在匯入套件前將 EXE 目錄傳給主程式與子行程。
- 目錄在讀取或儲存設定前建立。GUI 與 CLI 原本共用的設定常數仍共用同一新路徑，不依賴終端機工作目錄。
- 若新 `config/config.v3.toml` 不存在而舊 `~/.config/pdf2zh/config.v3.toml` 存在，啟動時逐位元組複製一次。使用排他建立模式，既有新檔不會被遷移覆寫；舊檔保持不變。
- `.gitignore` 排除 `config/`，避免個人設定與 API Keys 進入 Git。英文及繁體中文使用文件已更新。

## 測試

- 新增 4 項設定路徑測試：工作目錄獨立性、EXE／Python 安裝位置、拒絕相對覆寫目錄、舊檔遷移／不覆寫／儲存後重新載入。完整套件 **103 passed、73 warnings**，相較基準新增 4 項通過。
- 從 `.test-output` 工作目錄執行 `pdf2zh_next.exe --version` 成功；`config/default/2.9.0.toml` 實際出現在專案根目錄，該工作目錄沒有新增 `config/`。
- 本機舊 `config.v3.toml` 在新檔不存在時成功遷移；來源與目的 SHA-256 相同，新檔被 Git 忽略。之後以隔離設定目錄重跑完整測試，並確認個人設定檔雜湊未變。
- Ruff、`git diff --check`、PyStand 腳本語法檢查與 `uv pip check` 通過。

## PDF 回歸

- 使用與修改前相同的指定 4 頁 PDF、CLI 選項及離線翻譯 Mock；流程完成，耗時 **272.09 秒**，單語與雙語 PDF 均可開啟、渲染。
- 前後單語與雙語檔都為 4 頁；嵌入圖片總數分別維持 **23,998** 與 **47,996**；可擷取的公式符號總數分別維持 **48** 與 **98**。文字擷取量單語由 505,232 變成 505,225，雙語由 2,058,221 變成 2,059,307；此項受 PDF 版面／字型編碼影響，不能單獨判定功能退化。
