# Config 儲存責任拆分與競爭修復

修改前受控測試 **2 failed**：兩個儲存在寫入相同暫存檔後依序替換，第二次出現 `FileNotFoundError`；直接寫入版本預設檔時，序列化中斷會截斷原內容。

新增 `config/storage.py`，集中原有 TOML `None`／`"null"` 字典轉換與原子檔案儲存。每次寫入使用目的檔旁的唯一暫存檔，完成 flush／fsync 並關閉後替換目的檔；失敗清理暫存檔、保留原檔。ConfigManager 保留原方法與讀取／驗證責任，現有 TOML 格式、可攜式路徑及舊設定遷移均不變。舊暫存檔常數保留作相容匯出。

新增 4 項測試涵蓋共用暫存競爭、寫入中斷、替換失敗及獨立寫入者的暫存檔唯一性。修改後 Config＋日誌檢查 **80 passed、1 warning**；ruff 與 diff 檢查通過。

這不提供跨行程的讀取後修改交易鎖；同時儲存時最後一份完整設定勝出。替換失敗會回報例外，沒有加入重試／Backoff。沒有對突然斷電或不同檔案系統做耐久性保證。
