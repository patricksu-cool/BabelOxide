# 原生桌面介面

`pdf2zh-gui` 是 Windows 原生桌面視窗，以 Rust、eframe／egui 和內建 PDFium 預覽組成；翻譯仍透過隔離的 BabelDOC Python Worker。介面不啟動 Gradio 或網頁伺服器。預設介面語言為繁體中文，既有設定的語言仍會載入。

## 使用方式

1. 用檔案選擇器或拖放加入 PDF，可移除個別檔案並預覽原文。也可展開「下載 PDF 網址」，輸入公開的 HTTP 或 HTTPS PDF 連結，下載完成後加入相同的檔案清單。
2. 選擇翻譯服務、模型與所需憑證；「管理服務」可控制服務清單，停用服務不會刪除其既有設定。已選的服務被停用時，請重新啟用或切換服務。
3. 選擇來源與目標語言，可交換、使用下拉選單或展開自訂代碼。Qwen-MT、DeepL 的選單依本地實作已知限制過濾；其他服務支援情況請依服務確認，現有自訂代碼不會因不在清單而自動刪除。
4. 選擇輸出資料夾、譯文／雙語輸出及頁面。頁面快捷可選全部、第一頁或前五頁；自訂欄可輸入如 `1,3,5-10,-5` 或 `25-`。術語 CSV 可由選擇器加入，多個路徑以逗號分隔；術語設定與可用性依服務而定。
5. 速度、PDF 處理和其餘設定分組在折疊區。按「保存設定」寫入，錯誤會阻止保存；未辨識的設定會保留。敏感欄位依 schema 遮罩，設定禁止敏感輸入時不可編輯。
6. 開始翻譯後可查看進度或取消。選擇批次與檔案後，可用繁中頁籤預覽原文、譯文或雙語結果，開啟或另存單個檔案。成功批次提供全部 PDF、譯文 PDF 或雙語 PDF 的 ZIP 匯出；術語表另存功能保留，未納入上述 ZIP 選項。

網址匯入僅允許 HTTP 80 或 HTTPS 443，拒絕網址中的帳號密碼、片段、本機／內網或保留位址；每次重新導向都會重新檢查目的位址。下載大小上限為 100 MiB、總逾時 60 秒、連線逾時 10 秒，最多重新導向五次。可取消下載；下載檔須通過 PDF 檢查。下載客戶端會在冷啟動的首次網路操作初始化 TLS。此功能使用背景處理，下載檔案為本次應用程式工作階段的暫存輸入。

同一批次中若有相同檔名且輸出到相同資料夾的 PDF，GUI 會在輸出資料夾建立 `pdf2zh-batch-…/job-…` 子資料夾，分別保留結果並顯示提示。ZIP 內的重複檔名也會加上序號。一般單檔輸出路徑、核心與 Worker 維持原行為。

## 驗證界線

新版 Rust 工作區 292 項（其中 GUI 64 項）、Worker 35 項與 Builder 35 項測試通過。Release GUI 已實際操作語言與交換、服務及動態欄位、保存／重載／重開、PDF 加入／移除、頁面與術語選項、同名批次、三種 ZIP、冷啟動 HTTPS PDF 下載、失敗後再執行、取消、預覽／另存及處理中關閉。第三方服務的技術訊息保留原文；未逐一操作所有 235 欄或呼叫所有服務。

完整自用版為 `dist/gui-ux-20261101`，原 `dist/final` 保留。全檔雜湊驗證、中文空格路徑的完整隔離複本及指定 PDF 的固定回應回歸通過。精確成品、桌面測試範圍與未驗證邊界見 [最終狀態](../../docs/FINAL_STATUS.md)。

官方 v2.9.0 比較依 [官方原始碼](https://github.com/PDFMathTranslate-next/PDFMathTranslate-next/tree/v2.9.0)，未下載或執行官方 Windows 發行包。逐欄資料與差異見 [GUI 設定盤點](../../docs/GUI_SETTINGS.json) 及 [GUI 相容性稽核](../../docs/GUI_UX_AUDIT.md)。
